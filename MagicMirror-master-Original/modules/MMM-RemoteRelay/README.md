# MMM-RemoteRelay

Bridges a MagicMirror installation with the DumbMirror relay server so the Android app can reach the mirror outside the local network.

## Installation

```bash
cd modules/MMM-RemoteRelay
npm install
```

## Configuration

Add the module to `config/config.js`:

```javascript
{
  module: "MMM-RemoteRelay",
  position: "bottom_left", // or any other region
  config: {
    relayUrl: "http://localhost:8081",
    mirrorId: "<id returned by POST /api/mirrors>",
    mirrorSecret: "<secret returned by POST /api/mirrors>",
    heartbeatInterval: 30000,
    autoAcknowledge: true
  }
}
```

- `relayUrl`: Base URL of the relay server.
- `mirrorId` & `mirrorSecret`: Credentials generated by the relay when the mirror is registered.
- `heartbeatInterval`: Interval (ms) between heartbeat messages to keep the connection alive.
- `autoAcknowledge`: If `true`, the module automatically reports success after forwarding a notification to the MagicMirror bus.
